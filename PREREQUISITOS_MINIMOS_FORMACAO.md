## ✅ SUMÁRIO EXECUTIVO

O treinamento de 12 meses (600-700 horas) foi projetado para **"Intermediate developers/engineers"** e **"Graduate students"** com formação em engenharia, ciência da computação ou áreas relacionadas.

**Público-alvo direto:**
- 🎓 Mestrandos e doutorandos em engenharia
- 💼 Profissionais com 2-5 anos de experiência em programação
- 🔬 Pesquisadores em Building Performance Simulation

**Requisito crítico:** Nenhum pré-requisito formal, mas conhecimento prévio acelera significativamente o aprendizado.

## 🧠 CONHECIMENTOS PRÉVIOS MÍNIMOS ESPERADOS

### Nível 1: CRÍTICO (Deve Possuir)

#### 1.1 Programação
```
✅ Python intermediário
├── Sintaxe básica (variáveis, loops, funções)
├── Orientação a objetos (classes, herança)
├── Tratamento de exceções (try/except)
├── Manipulação de arquivos (leitura/escrita)
└── Experiência: 6+ meses ou 500+ linhas de código escritas

✅ Controle de Versão (Git)
├── Comandos básicos (git add, commit, push, pull)
├── GitHub ou GitLab
└── Experiência: Ter participado de 1+ projeto com versionamento

✅ Linha de Comando / Terminal
├── Navegação de diretórios (cd, ls, pwd)
├── Instalação de programas
├── Execução de scripts
└── Windows PowerShell OR Linux Bash (confortável com um deles)
```

#### 1.2 Matemática
```
✅ Álgebra Linear
├── Matrizes e vetores (multiplicação, transposição)
├── Sistemas lineares
└── Autovalores/autovetores (conceitual)

✅ Cálculo
├── Derivadas e integrais (conceitual)
├── Otimização: máximos/mínimos
└── Gradientes

✅ Estatística Básica
├── Distribuições de probabilidade
├── Média, mediana, desvio padrão
├── Testes de hipótese (conceitual)
└── Regressão linear
```

#### 1.3 Física e Thermodynamics (Mínimo)
```
✅ Conceitos de Calor e Temperatura
├── Transferência de calor (condução, convecção, radiação)
├── Lei de Fourier (Q = -k * dT/dx)
├── Capacidade térmica e calor específico
└── Entender por que edifícios precisam de isolamento

✅ Energia e Potência
├── Joule (J) e Watts (W)
├── Diferença entre energia e potência
├── Consumo de energia (kWh)
└── Eficiência energética básica

❓ NÃO PRECISA (será ensinado no Mês 1):
└── Detalhes de HVAC, cálculo de carga térmica complexa
```

### Nível 2: ALTAMENTE RECOMENDADO (Acelera Muito)

#### 2.1 Machine Learning Básico
```
✅ Conceitos Fundamentais
├── Supervisionado vs Não-supervisionado
├── Treino vs Teste (overfitting/underfitting)
├── Validação cruzada
└── Cross-validation

✅ Modelos Clássicos
├── Regressão Linear
├── Decision Trees (conceitual)
├── K-Nearest Neighbors
└── Entender tradeoff entre simplicidade e performance
```

#### 2.2 Análise de Dados
```
✅ Bibliotecas Python
├── Pandas (DataFrames, manipulação)
├── NumPy (arrays, álgebra linear)
├── Matplotlib (visualização básica)
└── SciPy (funções matemáticas)

✅ Técnicas
├── Limpeza de dados (missing values, outliers)
├── Agregação e agrupamento
├── Visualização de padrões
└── Análise exploratória de dados (EDA)
```

#### 2.3 SQL Básico
```
✅ Capacidade de
├── Executar SELECT básico
├── WHERE, GROUP BY, JOIN
├── Entender normalização (conceitual)
└── Conectar a banco de dados
```

### Nível 3: BOM TER (Interessante Mas Não Obrigatório)

#### 3.1 DevOps / Cloud
```
⭐ Docker (conhecimento básico)
├── Entender containers
└── Executar imagem Docker simples

⭐ Google Cloud / AWS
├── Criar conta e projeto
├── Executar VM ou instância
└── Entender modelo de cobranças
```

#### 3.2 APIs REST
```
⭐ Conceito de Requisições HTTP
├── GET, POST, PUT, DELETE
├── Status codes (200, 404, 500)
└── JSON / headers
```

#### 3.3 Simulação Energética
```
⭐ Experiência com EnergyPlus, TRNSYS, ou similar
├── Ter rodado uma simulação
├── Entender outputs básicos
└── Familiaridade com arquivos .idf ou .ddy
```
