### Common Issues & Solutions

**Issue:** Surrogate model accuracy too low
- **Solution:** Engineer better features, collect more training data, ensemble models

**Issue:** Federated optimization not converging
- **Solution:** Check communication between sites, adjust learning rates, increase iterations

**Issue:** A/B test shows no significance
- **Solution:** Increase pilot duration, larger treatment effect needed, check data quality

**Issue:** Operations resistance to new system
- **Solution:** Better training, demonstrate benefits, start with conservative settings
