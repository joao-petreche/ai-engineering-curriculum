## Troubleshooting & Support

### Issue: Data quality problems
**Symptoms:** Missing values, outliers, schema mismatches  
**Solution:** 
- Implement data validation rules (Exercise 1.2)
- Handle missing values intelligently
- Perform outlier detection and removal
- Reference: WEEK_1_DOMAIN_PROBLEM.md Exercise 1.2

### Issue: Surrogate model accuracy insufficient
**Symptoms:** R² < 0.90, large residuals  
**Solution:**
- Engineer better features (lag, rolling window)
- Collect more training data
- Ensemble multiple model types
- Reference: WEEK_1_DOMAIN_PROBLEM.md Exercise 1.3

### Issue: Federated optimization not converging
**Symptoms:** Objective value oscillates, slow improvement  
**Solution:**
- Check site communication, increase frequency
- Adjust FedAvg weights
- Reduce learning rates
- Increase iterations
- Reference: WEEK_2_OPTIMIZATION_PIPELINE.md Exercise 2.1

### Issue: A/B test shows no significance
**Symptoms:** P-value > 0.05  
**Solution:**
- Extend pilot duration
- Increase sample size
- Verify data quality
- Check for confounding factors
- Reference: WEEK_3_DEPLOYMENT_VALIDATION.md Exercise 3.1

### Issue: Production monitoring false alarms
**Symptoms:** Too many alerts, alert fatigue  
**Solution:**
- Calibrate alert thresholds
- Implement smart alerting (context-aware)
- Use anomaly detection over raw thresholds
- Reference: WEEK_3_DEPLOYMENT_VALIDATION.md Exercise 3.2

### Issue: Operations team resistance
**Symptoms:** Low adoption, reluctance to use system  
**Solution:**
- Improve training and documentation
- Show quick wins and benefits
- Start with conservative settings
- Build trust through reliability
- Reference: WEEK_3_DEPLOYMENT_VALIDATION.md Exercise 3.4
